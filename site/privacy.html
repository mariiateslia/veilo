Veilo processes images in your browser. Your screenshots are not uploaded to a server.

Last updated: November 17, 2026 · Applies to this website and Chrome beta @@VERSION@@.

The screenshot editor

When you open an image, Veilo reads it locally into the current tab. The image, masks, and rendered canvas remain in the tab’s memory. Veilo does not save them between visits or send them to a backend, AI service, or analytics service. Closing or reloading the tab clears the editor. Saving a PNG downloads a flattened copy to your device; the original file is unchanged.

The Chrome extension

The extension acts on the webpage you explicitly choose. It does not collect your browsing history or send page content anywhere. Selected elements stay in page memory and reset on reload or navigation. Your chosen mode and blur strength are saved in Chrome’s local extension storage on this device; no cloud sync is used. A visible-tab screenshot is captured only when you request it. For that capture, Chrome’s session storage temporarily holds the image to pass it to the editor; the editor removes it after reading it. If interrupted, session storage can retain it until the browser session ends.

Permissions: activeTab gives temporary access to the chosen tab; scripting adds the selection tools after your action; storage saves local mode/strength preferences and transfers a requested capture to the editor within the browser session. There are no blanket website permissions.

Blur and Cover have different purposes

Blur is a visual effect. It can leave information guessable or recoverable. For sensitive details in an exported screenshot, use Cover, which replaces the selected pixels in the saved PNG. Cover is drawn after every blur so an overlapping blur cannot expose covered pixels. Always review the entire export.

Effects on a live webpage only change its appearance. They do not delete data from that website. A website’s own scripts can still read its original content. Veilo is not a security boundary against a malicious page, browser extension, or person with access to the device.

This website and its hosting

Veilo adds no analytics, tracking cookies, advertising scripts, remote fonts, or user accounts. All product assets are served with the static website. Image editing itself makes no network requests. Downloading the beta and following a GitHub link are explicit actions.

The website is hosted on GitHub Pages. Loading the site and downloading files involves normal requests to GitHub’s infrastructure. GitHub may process technical request information, including IP addresses, under its own privacy statement ↗. The local-image-processing promise does not mean the hosting provider keeps no access logs.

Open source and feedback

The code is available under MIT. The generated background has separate asset terms documented in the repository. You can inspect the code or report a problem on GitHub ↗. Do not include private screenshots or credentials in a public issue.
