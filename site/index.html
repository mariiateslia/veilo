Read the privacy details ↗
Does Veilo upload my screenshots?

No. The editor opens and processes images in this tab. Your image is not sent to a server or saved between visits.

Is blur the same as redaction?

No. Blur is a visual effect and can leave information recoverable. Use Cover for private information in exported screenshots, and review the whole image before sharing. Page effects do not remove underlying website data.

Where does the extension work?

In desktop Chrome on ordinary webpages. Chrome internal pages, the Web Store, and the built-in PDF viewer are restricted. Effects reset on reload or navigation; dynamic pages can replace selected elements. The extension does not hide other desktop apps.

Why do I install the beta manually?

Veilo is not in the Chrome Web Store yet. Download the small ZIP and follow the illustrated guide. The code is public so you can inspect it before installing.
