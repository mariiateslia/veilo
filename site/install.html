01 / DOWNLOAD & UNZIP

Keep the whole Veilo folder.

Download the ZIP above, then extract it. On macOS, double-click the ZIP. On Windows, choose “Extract All.” Move the resulting Veilo folder somewhere permanent. Keep it there while the extension is installed.

The folder directly contains manifest.json, popup.html, and an assets folder. You do not need to open or edit any of these files.

02 / OPEN EXTENSIONS

Turn on Developer mode.

Type chrome://extensions in Chrome’s address bar and press Enter. Turn on Developer mode in the top-right corner. Then click Load unpacked.

Chrome’s Extensions page. Button placement can vary slightly by version.

03 / SELECT THE FOLDER

Select Veilo. Not manifest.json.

In the folder picker, navigate to the extracted Veilo folder. Open it, then click Select (or “Select Folder”). The files inside may appear greyed out — that is expected. Chrome is asking for a folder.

Select the folder itself. Do not choose the assets subfolder or the JSON file.

04 / TRY IT

Pin it. Pick a detail.

Open Chrome’s extensions menu (the puzzle-piece icon) and pin Veilo. Visit an ordinary webpage, click Veilo, and start selecting elements. Choose Blur or Cover. Press Esc to stop selecting; use Undo, Show all, or Pause to review your screen.

Want a screenshot instead? Use the extension’s capture action, or open an image in the web editor. For sensitive details in a PNG, use Cover and review the exported image.

When a page cannot be edited

Chrome’s own pages, the Chrome Web Store, and the built-in PDF viewer restrict extensions. Open an ordinary website to test Veilo. Effects reset when the page reloads or navigates. A dynamic page can replace a masked element; check again before sharing. Veilo does not hide your browser toolbar or other desktop apps.

Updating or removing the beta

To update, download the new ZIP, replace the contents of the existing Veilo folder, and click the extension’s reload icon at chrome://extensions. To uninstall, choose Remove on the Veilo card.
