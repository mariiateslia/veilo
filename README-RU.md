# Veilo — делись меньшим

[Сайт](https://mariiateslia.github.io/veilo/) · [Редактор скриншотов](https://mariiateslia.github.io/veilo/editor.html) · [Установка на русском](https://mariiateslia.github.io/veilo/install-ru.html)

Бесплатный редактор изображений и расширение для Chrome. Без сервера, аккаунтов, подписок и аналитики. Изображения обрабатываются локально в текущей вкладке.

В редакторе можно открыть PNG/JPG/WebP, нарисовать прямоугольные маски Cover или Blur, отменить действия и скачать PNG. Для чувствительных данных выбирай Cover: он заменяет выбранные пиксели в готовом файле. Blur — визуальный эффект, информация может остаться восстанавливаемой.

Чтобы установить бету, скачай ZIP с сайта, распакуй его, открой `chrome://extensions`, включи Developer mode и нажми Load unpacked. Выбери **всю папку Veilo**, внутри которой непосредственно находится `manifest.json`. Сам JSON выбирать не нужно.

Расширение работает на обычных веб-страницах в Chrome 120+ на компьютере. Внутренние страницы Chrome, Chrome Web Store и встроенный просмотрщик PDF ограничивают работу расширений. Эффекты на странице сбрасываются при обновлении или переходе. Динамический сайт может заменить скрытый элемент — перед демонстрацией проверяй экран.

Исходники, разработка и условия использования ассетов: [README](README.md). Код — MIT; сгенерированный фон имеет отдельные условия в [ASSETS.md](ASSETS.md).
