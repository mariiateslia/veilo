SHARE A LITTLE LESS

Your screen. Your boundaries.

Hide details on a webpage

  1. Open a normal website, then click the Veilo extension icon.
  2. Choose Blur or Cover and click Select on page.
  3. Click an element to hide it. Use Tab and Enter to select a keyboard-focusable element.
  4. Click Done or press Esc. The effect stays while you share your screen.
  5. Open Veilo again to pause, undo the last selection, or show everything.

Edit a screenshot

Click Edit a screenshot to capture the visible part of the current tab. Or open an image. Drag rectangles, choose Cover or Blur, then Save PNG. Keyboard users can add rectangles using the coordinate fields.

Know the boundaries

  • Page effects are temporary: reloading or navigating clears them. Recheck before sharing. Changing the mode changes all current page selections.
  • Blur changes the appearance only. It is not encryption or permanent redaction. Page data remains in the DOM and accessibility tree; selected content may still be copied or read by assistive tools.
  • Cover visually hides an element on the page. In exported screenshots, Cover replaces the selected pixels. Blur can leave information recoverable.
  • Chrome internal pages, the Web Store, built-in PDF viewer and other protected pages are unsupported. Enable file access in Chrome's extension settings for local file pages.
  • Only the top-level webpage is supported. Cross-origin iframe contents, closed shadow roots and individual text inside canvas apps cannot be selected. You can cover their containing element instead.
  • Dynamic websites can replace or move content. Masks are not guaranteed to survive every application update. Review the screen before recording.
  • Captures include the visible viewport only; browser toolbars and the rest of your desktop are not captured.

Privacy

Veilo has no server, account, telemetry, analytics or remote requests. It stores only your mode and blur strength in local extension storage. Selected elements stay in the current page's memory, not in a database. Captures are held temporarily in Chrome session storage, removed when opened, and cleared when Chrome closes. No cloud sync is used. Images in the editor remain in the tab's memory.

Permissions: activeTab accesses a page only after you open Veilo; scripting applies effects; storage saves preferences and temporarily transfers a screenshot to the editor.
